# Spam SMS Detection | CodSoft ML Internship – Task 4

## 📌 Objective
To build a machine learning model that classifies SMS messages as Spam or Ham.

## 🛠️ Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorizer
- Naive Bayes Classifier

## 📂 Dataset
SMS Spam Collection Dataset from Kaggle.

## ⚙️ Workflow
1. Load and clean dataset
2. Convert text into numerical form using TF-IDF
3. Train Naive Bayes model
4. Evaluate using accuracy and confusion matrix
5. Test with custom SMS input

## 📊 Results
- Achieved high accuracy on test data
- Model successfully detects spam messages
